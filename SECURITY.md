# Security

## Never commit a secret

`gitleaks` scans staged changes in the pre-commit hook. A hook can be bypassed,
so the control is not committing the secret. A committed secret is rotated,
not just deleted: it stays in history.

## Secrets at runtime, never rendered

- Terraform's own credentials come from the environment (an AWS profile, IAM
  Identity Center, or a CI role), never from a file in the repository.
- Secrets a running service needs are written to AWS by Terraform through
  write-only arguments (`value_wo`, `password_wo`), and read by the service when
  it runs.
- Nothing secret goes into `user_data`, a variable default, a `.tfvars` file,
  plan output or a command line.

## State is sensitive

The VPN's tunnel pre-shared keys are generated by AWS and kept in the hub stacks'
state; whoever can read that state can read them.

State can hold resource details that matter to an attacker. Access to it is
limited to the roles that plan and apply, and older versions are readable only
by administrators.
