# Security

## Never commit a secret

`gitleaks` scans staged changes in the pre-commit hook. A hook can be bypassed,
so the control is not committing the secret. A committed secret is rotated,
not just deleted: it stays in history.

## Secrets at runtime, never rendered

- Terraform's own credentials come from the environment (an AWS profile, IAM
  Identity Center, or a CI role), never from a file in the repository.
- Secrets never pass through Terraform: RDS keeps database passwords in Secrets
  Manager itself, and services read their secrets from Secrets Manager or SSM
  when they run. A secret Terraform must write goes through a write-only
  argument (`value_wo`, `password_wo`), so it never reaches state.
- Nothing secret goes into `user_data`, a variable default, a `.tfvars` file,
  plan output or a command line.

## State is sensitive

The VPN's tunnel pre-shared keys are generated by AWS and kept in the hub stacks'
state; whoever can read that state can read them.

State can hold resource details that matter to an attacker. The bucket refuses
anything not over TLS and limits each account to its own environments' keys;
within an account, IAM decides. Every pipeline role reaches only its own
environment's state, each apply role only its own duty's stacks, and a pull
request's role no state but its environment's and no stored plan at all. Old
versions are kept for recovery, and no pipeline role can delete one; a person
who can read the bucket can read them.

## Deployment permissions

No role in the pipeline has administrator access. Each environment's stacks are
split into duties, each applied by its own role, limited to its services, its
environment's resources and its own components, and never able to change the
pipeline, the state bucket, the organization, the trail or another environment.
Every role a stack creates carries a boundary that keeps it inside the same
limits. The roles, their limits and how each is tested are in
[accounts](docs/accounts.md#duties) and the
[threat model](docs/threat-model.md).
